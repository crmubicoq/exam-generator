# 04. 아키텍처 제안

## 1. 설계 원칙
1. **결정적 작업은 코드, 판단·작문은 LLM**
   - 코드: OCR 감지, 페이지 매핑, 단원 분할, 분포 추적, 보기 조합 생성, 근거 매칭, 하이라이트, Word/PDF 출력, 리포트
   - LLM: 진술·함정 작성, 해설 작성, 품질 판정, 기출과의 개념 중복 판단
2. **한 문항씩 생성 → 즉시 검증 → 실패 시 재생성(최대 3회)** — 기획안 v3.0의 Decider 루프
3. **분포는 사전 배정**: 생성 전에 30개 "슬롯"(단원·패턴·정답위치·함정라벨·난이도·유형)을 코드가 먼저 짜고, LLM은 슬롯을 채운다
   → 원예 회차의 사후 편향 문제를 구조적으로 제거
4. 모든 중간 산출물을 JSON 파일로 남긴다 (재실행·디버깅·수동 수정 가능)

## 2. 파이프라인
```
[입력] options.json + 교재 PDF + 기출 Excel
  │
  ▼ Phase 0 사전 준비 (코드)
  ├─ precheck: OCR 감지, 페이지 매핑 확정(footer 확인), 단원별 페이지 범위
  ├─ previous: 기출 Excel 파싱 → 개념/문장 인덱스(임베딩)
  ├─ planner: 매트릭스 → 30개 슬롯 배정 (분포 목표 충족하도록)
  └─ 자동 중단 조건 1·2 검사                  ◀ [검수형 정지점 ①]
  │
  ▼ Phase 1 문항 생성 루프 (슬롯마다)
  ├─ retriever: 슬롯 단원·범위에서 원문 청크 추출 (기출 영역 제외)
  ├─ Generator(LLM): 진술 4개 + 원문 근거 + 함정 유형 작성 (JSON)
  ├─ choice_builder(코드): 패턴·정답위치·자음분포·긴보기회피 만족하는 보기 생성
  ├─ Validator: 근거 매칭(코드, L1~L4) + 표현정확도(코드+LLM) + 기출회피(임베딩+LLM) + 품질6(LLM)
  ├─ Decider: 통과 / 재생성(피드백 포함, 최대 3회) / 수동확인 표시
  └─ tracker: 누적 분포 갱신, 5문항마다 중간 리포트
  │
  ▼ Phase 2 종합 검증 (코드) → validation_report  ◀ [검수형 정지점 ②]
  │
  ▼ Phase 3 산출물 (코드)
  ├─ Word 출제풀  ├─ 근거 PDF(줄 단위 하이라이트+라벨)  ├─ 단답 변환본  └─ 리포트
  │
  ▼ Phase 4 메일 초안 (LLM, 템플릿 기반)          ◀ [검수형 정지점 ③]
```

## 2-1. 기획안 v3.0 에이전트와의 대응
| 기획안 v3.0 | 이번 구현 |
|---|---|
| Generator | Generator(LLM) + choice_builder(코드)로 분리 |
| Deduplicator | Validator 내 기출회피 4단계 |
| Validator | 근거·표현·품질 검증 |
| Decider | 재생성 루프 컨트롤러 |
| Formatter | Phase 3 출력 모듈 |

## 4. 열린 결정사항 (GON 판단 필요)
| 항목 | 선택지 | 제안 |
|---|---|---|
| LLM 호출 경로 | Anthropic API 직접 / 사내 LiteLLM 경유 | llm_client.py 한 곳에 감싸서 어느 쪽이든 교체 가능하게. 키 관리·비용 정책에 따라 결정 |
| 실행 형태 | CLI / 웹 UI / Claude Code 대화형 | **MVP는 CLI**, 다음 단계에서 팀 서버에 웹 폼(옵션 입력·정지점 승인) |
| 임베딩(기출 회피) | KR-SBERT 로컬 / API 임베딩 / 키워드+LLM 판정 | 기출 210문항 규모면 LLM 판정만으로도 가능. 임계값은 원예 기출로 실측 후 결정 |
| 교재 텍스트 | PyMuPDF 추출(현행) / 재OCR | 현행 유지 + normalize. 매칭률 80% 미만 교재만 재OCR 검토 |
| 기출 DB 누적 | 매 회차 Excel / DB 누적 | MVP는 Excel, 이후 출제 완료분 자동 누적 |

## 5. 주의할 리스크
- 교재 PDF가 크다(295MB). 전체를 LLM에 넣지 말고 단원·페이지 청크만 전달.
- 근거 PDF 산출물도 크다(37MB). 필요한 페이지만 추출·압축 옵션 고려.
- v8 가이드 안의 기출회피·품질 검증 코드는 **의사코드**다(`compute_text_similarity`, `same_concept` 등 미구현). 실제 구현 대상.
