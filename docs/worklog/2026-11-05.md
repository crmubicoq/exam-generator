## Claude 계정 기능 (`exam_gen/claude_account.py`, 사이드바 AI 설정)
- 패키지에 든 Claude 프로그램의 `auth` 명령을 쓴다.
  - 확인: `auth status --json`. 로그인 여부, 이메일, 요금제(subscriptionType → Max·Pro·Team…), 조직 이름을 읽는다.
  - 로그아웃: `auth logout`.
  - 로그인: 새 콘솔 창에서 `auth logout` → `auth login --claudeai`. 브라우저에서 계정 승인 후 [계정 다시 확인]을 누른다.
- 화면
  - "로그인 계정: 이메일 · 요금제 · 조직"을 보여 준다. 로그인되어 있지 않으면 경고한다.
  - Pro·무료 요금제면 "300문항은 멈출 수 있어 30~100문항씩" 안내를 띄운다.
  - 버튼은 [다른 계정으로 로그인], [계정 다시 확인], [로그아웃]이다. 로그아웃은 확인 체크를 해야 누를 수 있다.
- 계정 확인은 세션마다 한 번만 한다. Claude 프로그램을 한 번 실행하는 데 1~2초가 걸리기 때문이다. 버튼을 누르면 다시 확인한다.
- 이메일은 화면에만 보여 주고 출제 기록·로그에는 남기지 않는다.
- 확인한 것
  - 이 PC 계정 상태 읽기: 요금제 Team으로 나왔다.
  - 사이드바 화면 테스트: 오류 없음.
  - 로그인 창 배치: 가짜 Claude 프로그램으로 실행해 로그아웃 → 로그인 → 안내 순서를 확인했다.
  - .exe가 아닌 경우에도 끝까지 돌도록 `call`을 붙였다.
- 확인하지 않은 것: **실제 로그아웃·로그인은 이 PC에서 누르지 않았다.** 개발 PC의 Claude 로그인이 풀리기 때문이다. 담당자 PC 설치 때 확인한다.
- `Claude_로그인.bat` 안내에 대시보드 방법과 '바꿀 때는 먼저 /logout'을 넣었다.
- 사용 매뉴얼 1절·11절·문제 해결 표와 README도 함께 고쳤다.
