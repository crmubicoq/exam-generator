# 03. 출제자 옵션 명세 (options.json)

출제자는 이 파일(또는 이후 UI 폼) 하나만 채운다. 비어 있는 항목은 시나리오 기본값으로 채운다.

## 1. 옵션 목록
| 키 | 설명 | 값 / 기본값 |
|---|---|---|
| `project_name` | 프로젝트명 | 예: "2026 E-TEST 원예기능사" (필수) |
| `textbook_pdf` | 교재 경로 (여러 권 가능) | 필수 |
| `previous_items` | 기출 Excel 경로 | 선택 (없으면 회피 단계 생략 + 리포트에 표시) |
| `scenario` | A 최상위 / B 일반+변별 / C 4단계 / D 단답만 / E 선다→단답 변환 | 기본 B |
| `total` | 총 문항 수 | 시나리오 기본값 |
| `type_ratio` | {mcq, short_answer} | B: 21/9 |
| `difficulty` | 난이도 구성 | B: 일반 최상 20 + 변별 핵심 10 |
| `pattern_ratio` | {A,B,C,D} % | B: 50/30/10/10 |
| `chapter_distribution` | 단원별 문항 수 | 기본: 기출 비율 비례 (원예 예: 채소8/과수7/원예생리6/화훼5/시설4) |
| `scope` | 출제 범위 (단원 or 페이지 범위) | 기본 전체 |
| `longest_choice_avoid_min` | 긴 보기=정답 회피 최소 비율 | 0.5 |
| `short_answer_policy` | {synonym, abbreviation, partial} | 표준/표준/all_or_nothing |
| `mode` | review(검수형) / auto(자동형) | 기본 review |
| `outputs` | 생성 산출물 | word, evidence_pdf, short_answer_conversion, validation_report, email_draft |
| `exam_type` | 상대평가 / 절대평가 | 상대평가 |
| `few_shot_samples` | 출제자 제공 샘플 문항 | 선택 (기획안: 유형·난이도별 9문항 이상 권장) |

## 2. 시나리오 기본값
| 시나리오 | 총 | 난이도 | 유형 | 패턴 |
|---|---|---|---|---|
| A 최상위 | 30 | 모두 최상 | 21/9 | A20 B40 C40 |
| B 일반+변별 ★ | 30 | 일반최상20 + 변별10 | 21/9 | A50 B30 C10 D10 |
| C 4단계 | 50 | 하10 중25 상15 | 40/10 | A60 B25 C10 D5 |
| D 단답만 | 20 | 상10 중10 | 0/20 | - |
| E 변환 | 기존 | 기존 | - | 패턴 D 제외 |

## 3. 운영 모드
- **review(검수형)**: 정지점 3회 — ① Phase 0 결과(매핑·매트릭스) ② 생성+검증 리포트 ③ 메일 초안
- **auto(자동형)**: 정지 없이 끝까지 진행, 자동 중단 조건(02 문서 11절) 발생 시에만 멈춤

## 4. 예시
```json
{
  "project_name": "2026 E-TEST 원예기능사",
  "textbook_pdf": ["input/원예기능사_필기_실기_필답형.pdf"],
  "previous_items": "input/2026_E-TEST_원예_기능사_기존문제.xlsx",
  "scenario": "B",
  "mode": "review"
}
```
