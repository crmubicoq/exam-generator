# 평가문항 출제도구 v1.2.0 업데이트 안내

실사용 중에 주신 '오류 및 수정 요청' 11건과 확인 답변을 반영했습니다. 업데이트해도 출제 데이터는 그대로 유지되고, 처음 실행할 때 자동으로 백업됩니다.

## 업데이트 방법
1. 프로그램을 끕니다(검은 창 닫기).
2. `출제도구_v1.2.0_프로그램만.zip`을 풀어 설치 폴더에 **덮어쓰기**합니다.
3. `실행.bat`으로 다시 켭니다. 왼쪽 사이드바 맨 아래에 **v1.2.0**이 보이면 완료입니다.
4. 검수 화면을 처음 열면, 승인 전 문항을 바뀐 기준으로 한 번 다시 확인합니다(AI 사용 없음, 몇 초). 이때 막혀 있던 문항 일부가 풀릴 수 있습니다.

## 바뀐 점

### 1. 검수자 판단으로 승인 (요청 1·3·10)
- 승인이 막힌 문항 아래에 **[검수자 판단으로 승인]** 상자가 나옵니다. 막힌 사유가 무엇이든 쓸 수 있습니다.
- 사유를 확인하고 "책임지고 승인합니다"에 체크한 뒤 누르면 승인됩니다. 이때 검수자 이름이 필요하고, 판단 메모는 적는 것을 권합니다.
- 승인 기록에 **막혀 있던 사유·검수자·메모**가 남습니다.
  - 엑셀 '검증 메모'(숨김 열)와 품질 리포트에 '검수자 판단 승인'으로 표시됩니다.
- 승인한 뒤 문항을 다시 고치면 이 승인은 풀립니다.

### 2. 난이도 판정 차이는 참고만 (요청 3, 담당부서 확인)
- AI가 판정한 난이도가 출제 난이도와 달라도 **승인을 막지 않습니다.** 검수 화면에 참고로만 표시됩니다.

### 3. 단답형 근거 대조 개선 (요청 3)
- **유사답변** 중 하나가 정답 근거 인용문에 있어도 통과합니다.
- 맞지 않으면 "정답 ○○(유사답변 포함)이 근거 인용문에 없음 — 인용문: …"처럼 무엇이 안 맞는지 보여 줍니다.
- 근거 인용문의 '대상' 칸을 '정답'이나 '1'로 적어도 정답 근거로 인정합니다.

### 4. 수정 메모 오류 수정 (요청 4)
- 수정 메모가 다음 문항으로 넘어가도 남아 있던 오류를 고쳤습니다. 문항마다 메모 칸이 따로 있고, 저장하면 비워집니다.

### 5. 기출로 이 프로그램의 엑셀을 올린 경우 (요청 5, 담당부서 확인)
- 이 프로그램에서 내려받은 엑셀을 같은 프로젝트의 기출로 올리면, **이미 이 프로젝트에 있는 문항은 자동으로 건너뜁니다.** 이 프로젝트의 문항은 원래 중복 검사에 쓰이므로 따로 올리지 않아도 됩니다.
- 이미 그렇게 등록된 기출이 있으면, 기출문제 등록 화면에 안내와 **[똑같은 기출 N문항 지우고 다시 확인]** 버튼이 나옵니다. 누르면 '자기 자신과 100% 중복'으로 막혔던 문항이 다시 확인됩니다.
- 기출을 저장하면 이미 만든 문항과 **바로** 비교합니다. AI 재검증 때 갑자기 중복으로 잡히는 일이 없습니다.
- 기출 파일을 지운 뒤 출제하면 기존 문항이 덮어써지던 오류를 고쳤습니다. 이제 기출 파일을 지워도 됩니다.

### 6. 페이지 재출제 자동 배정 (요청 6)
- **'페이지별 문항 수 직접 지정'을 끌 수 있습니다.**
- 끄면 '다시 출제할 문항 수'만 넣으면 됩니다. 그러면 **문항이 없는 페이지**(또는 기존 문항이 정한 수 이하인 페이지)에 자동으로 배정합니다.
- 켜면 지금처럼 페이지마다 직접 넣습니다.

### 7. 보류 (요청 7)
- 검수 화면의 **[보류]**에서 사유(중복 의심·내용 확인·기타)와 메모를 넣어 보류할 수 있습니다.
- 보류한 문항은 '보류' 대기열에 모입니다. **[보류 풀기]**로 되돌릴 수 있습니다.
- 출력 화면에서 **'보류 문항 포함'**을 고를 수 있습니다(기본 포함). 포함하면 엑셀에 **연한 보라 행**으로 표시되고, 숨김 열 '검증 메모'에 보류 사유가 남습니다.

### 8. 엑셀 열 (요청 8, 담당부서 확인)
- **C열**을 보이게 하고 제목을 **'출처 페이지'**로 바꿨습니다(원고 쪽수).
- **R열 '문항ID'**(예: K00012)와 **S열 '출제 회차'**(예: 2회차 · 추가 출제)를 보이는 열로 추가했습니다.
- 이의신청 조회 화면에서 문항ID로 바로 찾을 수 있으니, 업로드한 문항과 함께 보관해 두시면 좋습니다.

### 9. 검사 이름 표시 (요청 9)
- 'G2'처럼 번호만 나오던 사유를 **'근거 대조(G2)'**처럼 이름과 함께 보여 주고, 아래에 검사별 설명을 붙였습니다.
- 같은 사유는 한 번만 표시합니다.
- 숫자 검사는 어느 진술의 어떤 숫자인지 함께 보여 줍니다.
  - 예: "참 진술의 수치 1이(가) 근거 원고 쪽에 없음 — 진술: …"
  - AI가 원고에 없는 숫자를 지어내는 것을 막는 검사입니다.

### 10. 원고에 있는 '1페이지' 같은 용어 (요청 10)
- '관리자 1페이지 보고'처럼 **근거 원고에 실제로 있는 표현**은 쪽수 노출 규칙에 걸리지 않습니다.

### 11. 출제 옵션 화면 (요청 2·11)
- 난이도 보정을 쓸 때 **① 목표(최종 판정 기준) · ② 출제 지시(AI에게 요청) · ③ 예상 판정**을 한 표로 보여 주고, 두 숫자가 다른 이유를 설명합니다.
- 난이도 비율 옆에 '목표 N문항 · 출제 지시 M'을 함께 표시합니다.
- 추가 출제의 수량 입력은 **'총 수량 + 난이도 %'** 하나로 통일했습니다.

### 그 밖의 오류 수정
- 객관식 기출을 먼저 올린 뒤 원고를 등록하면 나던 오류를 고쳤습니다.
