# 평가문항 출제도구 v1.1.0 업데이트 안내

v1.0.0 설치 후 주신 의견을 반영했습니다. 업데이트하면 출제 데이터는 그대로 유지되고, 처음 실행할 때 자동으로 백업됩니다.

## 업데이트 방법
1. 프로그램을 끕니다(검은 창 닫기).
2. `출제도구_v1.1.0_프로그램만.zip`을 풀어 설치 폴더에 **덮어쓰기**합니다.
3. `실행.bat`으로 다시 켭니다. 왼쪽 사이드바 맨 아래에 **버전 v1.1.0**이 보이면 완료입니다.

## 바뀐 점

### 1. Claude 계정 확인 창
- 처음 실행하거나 계정이 바뀌면 **"이 PC는 ○○ 계정으로 출제합니다"** 확인 창이 뜹니다.
- 새로 설치했는데 이미 로그인되어 있는 것은 정상입니다. Claude 로그인 정보는 프로그램이 아니라 PC의 윈도우 사용자 폴더에 저장되므로, 그 PC에서 전에 로그인한 계정이 그대로 보입니다.
- 계정이 다르면 확인 창에서 **[다른 계정으로 로그인]**을 누르세요.

### 2. 검수 완료·미검수 알림
- 남은 문항을 모두 승인·삭제하면 **검수 완료** 창이 뜨고, 바로 출력 화면으로 갈 수 있습니다.
- 검수하지 않은 문항이 남은 채 출력 화면에 들어오면 **알림 창**이 뜹니다.

### 3. 엑셀에 난이도 표시
- 제출 양식 칸(A~P) 오른쪽 **Q열**에 난이도가 나옵니다.
- 담당자가 정한 난이도가 있으면 그 값을, 없으면 AI 판정 값을 씁니다.

### 4. 원고 근거 새 창에 해설 추가
- 듀얼 모니터용 '원고 근거 새 창'에서 문항·보기별 근거와 함께 **해설**도 볼 수 있습니다.

### 5. 급할 때: 고친 문항을 AI 재검증 없이 바로 승인
- 문항을 고치면 원래는 AI 재검증(문항당 약 30초~1분)을 받아야 승인할 수 있었습니다.
- 이제 고친 문항에는 **[AI 재검증 없이 승인]** 버튼이 함께 나옵니다. 담당자가 고친 내용을 직접 확인하고 바로 승인할 때 씁니다.
- **자동으로 건너뛰는 문항은 없습니다.** 버튼은 직접 고친 문항에만 나오고, 문항마다 아래 두 가지를 해야 승인됩니다.
  - "직접 확인했고 책임지고 승인합니다"에 체크
  - 검수자 이름 입력
- 형식·원고 근거·규칙·중복 검사는 그대로 통과해야 합니다.
- 이렇게 승인한 문항은 'AI 검증 생략' 목록에 남고, 출력 화면 위쪽에 **"아직 AI 검증 전 N문항"** 안내가 보입니다.
  - 시간이 날 때 품질 리포트의 **[생략한 AI 검증 실행]**으로 한꺼번에 검증하세요. 통과하면 승인이 그대로 유지됩니다.
  - **납품 전에는 꼭 검증해 주세요.**
- 버튼을 숨기려면 왼쪽 사이드바 **AI 설정 → 검수 설정**에서 끄면 됩니다.

### 6. 중지 버튼
- 출제 진행 화면의 **[중지]**를 진행률 바로 옆으로 옮겼습니다.
- 품질 리포트의 '생략한 AI 검증 실행'도 진행률과 **[중지]**가 생겼습니다.
  - 뒤에서 실행되므로 다른 화면을 봐도 계속됩니다.
  - 다시 실행하면 남은 문항부터 이어서 합니다.

## 확인 부탁드립니다
- 엑셀 **Q열(난이도)**이 문항 업로드 시스템에 올릴 때 문제가 없는지 확인 부탁드립니다. 문제가 있으면 다른 위치로 옮기거나 끌 수 있게 바꾸겠습니다.
- 'AI 재검증 없이 승인'으로 처리한 문항을 **언제까지 검증할지**(예: 납품 전 반드시) 정해 주시면 안내에 반영하겠습니다.

문의할 때 사이드바 맨 아래의 **버전 번호**를 함께 알려 주시면 빠르게 확인할 수 있습니다.
