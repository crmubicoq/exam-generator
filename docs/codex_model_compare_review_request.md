# 출제 모델 비교 교차 검수 요청 (Codex) — 블라인드 64문항

## 1. 목적과 방식
같은 원고·같은 출제 슬롯 32개로 **서로 다른 출제 설정**에서 만든 두 묶음(X, Y)의 문항 품질을 비교한다. 300문항 본출제에 어떤 설정을 쓸지 정하는 근거로 쓴다.

- **블라인드**: 어느 묶음이 어떤 AI·모델로 만들어졌는지 알려 주지 않는다. 판정이 끝날 때까지 추측하지 말고, `projects/` 아래 다른 프로젝트 폴더·문항 DB(`items.sqlite`)·`runs/` 기록은 **열지 않는다**(모델 정보가 들어 있다).
- 읽기 전용. 파일 수정 금지, 출제 파이프라인·LLM 호출 금지. 원고 문장은 근거를 식별할 만큼 짧게만 인용한다.
- 결과는 **표준 출력으로만** 내보낸다(호출 측이 `docs/codex_model_compare_review_result.md`로 저장한다).
- 두 묶음에 **같은 기준**을 적용한다. 한 묶음을 먼저 다 보고 다른 묶음을 보면 기준이 흔들리기 쉬우니, **같은 슬롯 번호끼리 짝지어** 보기를 권한다.

## 2. 대상
| 항목 | 위치 |
|---|---|
| 원고 | `원고/[1권] 지키는 AI, 돕는 AI, 농업인을 위한 AI실무 가이드_원고_2026.10.19.pdf` (PDF 쪽 = 책 쪽) |
| **묶음 X** (32문항) | `projects/_교차검수_모델비교_블라인드/묶음_X.md` |
| **묶음 Y** (32문항) | `projects/_교차검수_모델비교_블라인드/묶음_Y.md` |
| 출제 기준 | `exam_gen/spec/criteria.yaml`(난이도 루브릭), `exam_gen/llm/prompts/generate_system.j2`(출제 지침), `exam_gen/validate/rules.py` |
| 이전 검수 기준 | `docs/codex_real_review_request.md` 4절(판정 항목 1~10)·6절(보고 형식) |

- 문항마다 슬롯 번호·차시·쪽·유형, 목표/출제 후 난이도, 자동 검증 상태, 발문·보기·정답·해설, **출제 AI가 단 근거 인용**(참/거짓 보기 근거, 함정 설명)이 있다.
- 자동 검증(G4 독립 풀이·G5 검수) 결과는 일부러 넣지 않았다. 독립적으로 판정해 달라.
- '자동 검증 탈락(수동확인)' 문항도 포함되어 있다. 탈락 문항도 같은 기준으로 판정하되, 표에 탈락 문항임을 표시한다.
- 참고: 두 묶음은 출제 시점이 달라 **최상 난이도 지침 버전이 다를 수 있다**. 최상 슬롯은 비교에서 따로 표시해 달라.

## 3. 판정 기준
`docs/codex_real_review_request.md` 4절의 항목 1~10을 그대로 쓴다. 특히 다음을 중점으로 본다.
1. **정답 성립**: 정답이 원고로 입증되는가, 거짓 보기를 원고로 거짓이라고 확정할 수 있는가(양립 가능·조건 부족이면 치명).
2. **근거 인용**: 인용문이 그 쪽에 실제로 있는가, 인용이 해당 보기의 참·거짓을 실제로 뒷받침하는가.
3. **정답 단서**: 상식·어조·길이·전칭 표현·자기 반복만으로 풀리는가.
4. **형식**: 물음표 누락, 문항 밖을 가리키는 표현('이 사례', '위 사례', '사례 A' 등), 단답형 빈칸 정답어가 지문에 노출되는지.
5. **난이도 표시**: 출제 후 난이도가 문항 구조와 맞는가(목표와 다르다는 것만으로 오류로 세지 않는다).
6. **같은 원리 반복**: 한 묶음 안에서 같은 판단 원리를 반복해서 묻는 문항.

## 4. 보고 형식
1. **문제 문항 표** — 묶음·문항 번호(예: X07)·슬롯·심각도(치명/높음/중간/낮음)·항목·문제·근거(쪽·짧은 인용)·수정안. 문항별 가장 높은 심각도로 한 번만 집계한다.
2. **묶음별 요약** — 심각도별 건수, 문제없음 문항 수, **그대로 서비스 가능 비율**, 근거 인용 확인 결과(확인 개수/전체).
3. **슬롯별 비교** — 32개 슬롯마다 X·Y 중 어느 쪽이 나은지(X 우세 / Y 우세 / 비슷)와 한 줄 이유. 최상 슬롯은 표시.
4. **종합 판단** — 두 묶음의 품질 차이가 300문항 본출제 설정을 바꿀 만큼 의미 있는가, 어느 묶음이 나은가, 그 이유. 문항 수가 적어 생기는 불확실성도 적는다.
5. 체감 난이도·정답 단서 판단은 문항 구조에 근거한 **추정**이면 "추정"으로 표시한다.
