# E-TEST 문항 자동 출제 에이전트 — 개발 인계 패키지

작성일: 2026-10-20
작성 근거: claude.ai 대화방(2026-04 기획안 v3.0 → 2026-05 안전·원예 실전 출제 → 스킬가이드 v8)의 결정·코드·교훈 전체

## 이 패키지의 목적
관련 부서 요청: **"원고(교재 PDF)를 첨부하면 출제자가 고른 옵션에 따라 문항을 자동 출제해주는 솔루션"**을
VS Code + Claude Code 환경에서 에이전트 형태로 구현하기 위한 출발 자료입니다.
지금까지는 claude.ai 프로젝트(가이드 docx + 지침 + 대화)로 사람이 대화하며 운영했고,
이번부터는 이를 **코드로 된 파이프라인**으로 옮깁니다.

1. 새 리포 생성 (예: `crmubicoq/etest-question-agent`) → 이 폴더 내용 복사
2. `CLAUDE.md`를 리포 루트에 두고 커밋
3. Claude Code에서 `docs/08_개발로드맵.md`의 "첫 지시문"부터 한 단계씩 진행
