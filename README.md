# 평가문항 자동 출제 툴 (프로토타입)

원고(PDF·PPTX·DOCX·HWP)를 넣으면 출제자 대시보드에서 고른 옵션대로 성인 온라인 강의 평가문항(선다형·진위형·단답형)을 출제한다.
출력은 **양식 엑셀**과 **근거PDF**(원고 위에 출처를 하이라이트로 표시)다.

## 실행
```
setup.bat      # 처음 한 번: 가상환경과 패키지 설치
run.bat        # http://localhost:8620
```
LLM은 사이드바 **LLM 설정**에서 고른다.

| 공급자 | 용도 |
|---|---|
| 데모(mock) | LLM 없이 원고 문장으로 모의 문항을 만든다. 화면 흐름 확인용이며 납품에 쓰지 않는다 |
| Anthropic API | API 키 |
| 사내 LiteLLM | OpenAI 호환 주소와 키 |
| Claude Agent SDK | 이 PC에 로그인된 Claude Code 구독을 쓴다 |

## 흐름
1. **원고 등록**: 업로드 → 책 쪽수 매핑 확인(확정 전에는 출제 불가) → 페이지별 차시·출제 제외 → 학습목표
2. **출제 옵션**: 문항 수(기본 300 + 여유 5%), 난이도 % 4칸(최상·상·중·하), 유형 %, 페이지 할당(자동/강제)
   - 추가 출제는 난이도별 수량 또는 총 수량 + %로 입력한다.
3. **출제 진행**: 진행률, 관문별 탈락, 페이지 커버리지(0문항·과밀 경고), 중지·재개
4. **검수**: 문항과 원고 하이라이트를 나란히 보고 수정·승인·삭제한다. **승인한 문항만 최종 출력에 들어간다.**
5. **출력**: 양식 엑셀(최종 시트, 숨김 검수용 시트, 검증리포트), 근거PDF(문항별 추출본, 원고 전체 표시본)

CLI: `python -m exam_gen.cli new|run|export|report` (exam_gen/cli.py 참고)

## 신뢰도 장치 — 문항 하나가 통과해야 하는 관문
| 관문 | 내용 | 코드 |
|---|---|---|
| G1 구조 | 슬롯 명세(유형·정답 위치·옳은/옳지 않은)와 정답 논리 | validate/schema.py |
| G2 근거 | 근거 인용문을 원고에서 찾아 줄·bbox·**책 쪽수를 코드가 확정**. 못 찾거나 참 진술의 수치가 근거에 없으면 탈락 | validate/evidence.py |
| G3 규칙 | 문어체, 단답 조사 힌트, 조합형 '모두', 진위형 O 해설 반복, 표현 정확도(의무·금지·가능·권고), 절대어 | validate/rules.py |
| G4 독립 풀이 | 정답을 숨기고 원고만으로 다시 풀어 정답과 보기별 참·거짓을 대조 | validate/solver.py |
| G5 LLM 검수 | 지침 [8] 검토 항목 + 출제 유의사항 체크리스트 + 실제 난이도 판정(두 단계 이상 차이면 탈락) | validate/review_llm.py |
| G6 중복 | 기존 전체 문항과 어절 자카드·판단 포인트·근거 위치 비교 | validate/dedup.py |
| G7 승인 | 사람 승인. 승인할 때 G1~G3를 다시 검사한다 | review_ops.py |

- 탈락한 슬롯은 사유를 붙여 다시 출제한다(기본 3회). 그래도 실패하면 '수동 확인'으로 남기며 자동으로 출력되지 않는다.
- 첫 시도 근거 매칭률이 80% 미만이면 **자동 중단**한다(OCR 원고 점검 신호).
- 모든 생성·탈락·수정·승인은 `items.sqlite`의 events 테이블에 남는다. 사용 모델, 프롬프트 버전, 원고 해시도 함께 기록한다.

## 원고 전반 출제
- `plan/coverage.py`가 출제 가능한 페이지의 글자 수에 비례해 문항 수를 나눈다.
  - 페이지마다 최소 1문항, 최대는 기대값의 2배다.
- `plan/slots.py`가 생성 전에 유형·난이도·정답 위치(①~④ 각 25%)·O/X(5:5)·옳은/옳지 않은(20:80)을 슬롯으로 확정한다.
- 생성은 페이지 단위로 한다. 같은 페이지의 기존 문항은 회피 목록으로 넘긴다.
- 추가 출제는 기존 문항이 기대보다 적은 페이지에 더 배분한다.

## 담당자와 정할 것
- LLM 경로(API 키 / 사내 LiteLLM / 구독)와 모델
- 유형별 기본 비율(현재 선다 50 / 진위 30 / 단답 20), 난이도 기본값(최상 5 / 상 15 / 중 60 / 하 20)
- 문항번호 방식(양식 연번 / 유형별), NCS 열(N~P) 채움 여부
- 장 단위 원고에서 차시를 나누는 기준
- 단답형에 '상·최상' 난이도를 배정할지. 단답형은 실제 난이도를 올리기 어려워 '수동 확인'으로 빠지기 쉽다.
- 웹 검색 기반 사실 검증(지침 [8]-6)은 아직 구현하지 않았다.
