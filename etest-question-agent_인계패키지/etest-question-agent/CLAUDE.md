- 한 번에 한 단계씩, 작고 되돌릴 수 있게 진행. 큰 변경 전에는 계획을 먼저 보여주고 확인받기.

- 문서 3갈래: `docs/devlog.md`(기술 기록, Claude가 작성) / `docs/worklog/날짜.md`(작업일지, Claude가 작성) /
  `docs/decisions/날짜.md`(GON이 정한 판단 — **Claude Code는 이 폴더를 수정하지 않음**).

## 도메인 절대 규칙 (상세: docs/02_출제규칙_명세.md)
1. 교재에 없는 내용 생성 금지. 모든 진술에 교재 페이지 + 원문 근거(evidence_text) 필수. 근거를 못 찾으면 출력 차단.
2. 원고의 의무/금지/가능/권고 표현(해야 한다/해서는 안 된다/할 수 있다/권장한다)을 바꾸지 않는다 — 함정으로 의도한 경우 제외.
3. 페이지는 책에 인쇄된 페이지 번호 기준. PDF 인덱스와의 매핑은 Phase 0에서 확정한다.
4. 문항은 한 개씩 생성·검증한다 (일괄 생성 금지).
5. 결정적으로 계산 가능한 것(분포·매핑·하이라이트·포맷)은 LLM이 아니라 Python 코드로 처리한다.

원예기능사 OCR PDF에서 실전 검증됨. 새로 짜지 말고 이걸 기반으로 모듈화할 것.
