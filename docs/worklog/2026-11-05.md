  - 로그아웃: `auth logout`.

### 3. 검수 화면 개편 (`app_pages/review.py`, 새 `exam_gen/review_view.py`)
- 세 칸으로 나눴다: 왼쪽 문항 목록 · 가운데 문항 · 오른쪽 원고 근거. 예전에는 문항과 원고 근거가 탭으로 나뉘어 동시에 볼 수 없었다.
- 목록 높이는 창 높이에 맞춘다(`max-height: calc(100vh - 21rem)`). 목록 바로 아래에 이전·다음(‹ n / N ›)을 두었다. 50문항 단위 목록 쪽은 현재 문항을 따라간다.
- **보기·진술·정답마다 바로 아래에 근거 인용문**을 붙였다.
  - 노랑은 참 진술 근거, 파랑은 함정 원문이며 쪽·일치 수준·바꾼 점을 함께 보인다.
  - 어느 보기에도 붙지 않는 인용문은 '그 밖의 근거 인용문'으로 따로 보인다.
- 문항 칸의 상자 안 스크롤을 없앴다. 문항 수정·검증 상세·이력은 문항 아래 펼침으로 옮겼다.
- 오른쪽 원고 근거는 스크롤해도 화면에 붙어 있다.
  - 처음에는 고정이 동작하지 않았다. 고정을 상자에 걸었는데, 감싸는 틀이 상자와 같은 높이라 붙어 있을 공간이 없었다.
  - 고정을 감싸는 틀(stLayoutWrapper)에 걸어 해결했다.
- **원고 근거를 새 창으로 보기** 스위치
  - 켜면 오른쪽 칸이 빠지고 [원고 근거 새 창 열기]가 나온다.
  - 새 창(`app_pages/evidence_window.py`, 주소 `/evidence`, 사이드바 없음)은 `ui_state.json`의 `review_current`를 2초마다 확인한다. 검수에서 문항을 바꾸면 따라간다(듀얼 모니터용).
  - 원고 PDF·이미지는 같은 문항이면 다시 만들지 않도록 캐시한다.
  - 확인: 새 창이 K00001에서 K00002로 따라가는 것을 화면 테스트로 봤다.
- 출력물(엑셀·근거PDF·시험지)은 바뀌지 않는다. 화면에 보이는 위치만 바꿨다.

### 4. 출제 옵션 순서 (`app_pages/options.py`)
- 순서를 출제 종류 → **문항 수** → 난이도·유형 비율·세부 옵션 → 페이지 배분 → 출제 전 점검으로 바꿨다. 계산은 그대로다.
- 최초 출제는 "실제 출제 N문항 = 필요 + 여유분"을 보여 준다.
- 추가 출제의 '총 수량 + 난이도 %'는 비율을 정한 뒤 난이도 구성을 계산해 보여 준다.

### 1. 쪽 번호 입력 (`app_pages/register.py` ③)
- 쪽 번호가 모두 숫자인 원고는 시작 쪽·끝 쪽을 숫자 입력칸에 넣고 Enter로 입력한다. 적용은 [적용] 버튼으로 한다.
- 입력하면 '적용 범위: 원고 ○쪽 ~ ○쪽(○장)'을 보여 준다. 원고에 없는 쪽 번호면 안내하고 적용을 막는다.
- 쪽 번호에 숫자가 아닌 것(로마 숫자 등)이 있으면 예전처럼 목록에서 고른다.
