# 실제 원고 시험 출제 교차 검수 요청 (Codex) — 300문항 출제 전

## 1. 목적과 검수 방식
실제 납품 원고로 시험 출제한 문항을 **출제 전문가 입장에서 독립적으로 검수**해 달라. 이 결과를 보고 300문항 본 출제를 진행할지 정한다. 문항 오류는 다른 팀 서비스에 그대로 나가므로 엄격하게 본다.

- **읽기 전용**: 파일을 수정하지 않는다. 결과는 `docs/claude_real_review_handoff.md` 한 파일로만 작성한다.
- **LLM 호출 금지**: 출제 파이프라인(`python -m exam_gen.cli run`)을 실행하지 않는다.
- **판단 근거**: 원고 PDF와 아래 기준 문서만 쓴다. 다만 "원고 밖 상식·실무로 다른 답을 우길 여지"는 지적한다.
- **원고 보안**: 원고 파일과 `projects/` 폴더는 git에 올리지 않는다. 원고 문장을 보고서에 길게 옮기지 않는다(근거는 쪽수와 짧은 인용으로).

- 학습목표: 원고에 없어 머리말·목차로 임시 작성했다(프로젝트 meta.json의 objectives).

문항 읽는 법:
```python
import sqlite3, json
rows = sqlite3.connect("projects/1권_지키는_AI_돕는_AI_농업인을_위한_AI실무_가이드_시험2/items.sqlite").execute("select data from items").fetchall()
items = [json.loads(r[0]) for r in rows]
# key, type(mcq/ox/short), difficulty(실제), difficulty_target(목표), stem, statements, choices[{text,is_true}],
# answer, short_variants, explanation, evidence[{target, quote, is_true, trap_note, match{label, level}}], validation{warnings}
```
`python -m exam_gen.cli report <프로젝트 폴더명>`으로 문항 전체를 텍스트로 볼 수 있다(LLM 호출 없음).

## 3. 시험 1 → 시험 2 사이에 바꾼 규칙 (효과를 판정해 달라)
1. **어조 균형**: 거짓 보기만 단정적·과신하는 표현이면 원고를 몰라도 정답이 보인다. 시험 1에서 '정답 단서' 12/30건 대부분이 이 유형이었다(이 원고는 "~할 수 있다", "~만으로는 확정할 수 없다" 같은 조심스러운 문장이 대부분).
2. **인용 세부 출제 금지**: 어느 기관·보고서의 내용인지, 평가지표·과업 약어, 대회 성적을 묻지 않는다(시험 1의 K00016·K00018·K00030 유형).
3. 단답형 괄호가 둘 이상이면 '공통으로' 표시(자동 수정·검사).
4. 학습목표에 1절(생성형 AI 원리·업무 활용 확인 원칙) 추가.
5. (10/21 반영분) 거짓 보기는 원고 문장과 실제로 모순되어야 함, 조합형 라벨 빈도 단서 차단.

### 시험 2 자체 점검 결과 (Claude) — 판정해 달라
- 해결: 인용 세부 문항 3 → 0, '공통으로' 누락 자동 수정, 1절 '학습목표 무관' 경고 3 → 0, 형식 경고 30% → 23%.
- **미해결: G5 '정답 단서' 12/30 → 18/30.** G5 검수 기준도 같이 엄격해졌으므로 단순 비교는 어렵다.
- Claude의 해석: 이 원고의 핵심 메시지가 "기술·친숙함·단서를 과신하지 말고 확인하라"여서, 거짓 보기가 거의 항상 **과신 진술**("탐지되지 않으면 진짜로 판정할 수 있다", "확인을 생략할 수 있다")이 된다. 그래서 상식만으로 걸러진다. 프롬프트의 '어조 균형' 문구만으로는 바뀌지 않았다.
- **질문**: (a) 이 해석이 맞는가. (b) 오답을 '다른 항목·단계·주체와 맞바꾸기'로만 만들도록 강제하는 방안(출제 AI가 오답 유형을 표시하고 '과신형'이면 코드가 탈락시킴)이 타당한가, 다른 방법이 있는가. (c) 태도·원칙 중심 과정에서 상식으로 풀리는 문항을 어느 수준까지 허용할지 기준을 제안해 달라. (d) G5의 '정답 단서' 지적 18건 중 실제로 타당한 것은 몇 건인가.

## 4. 문항마다 볼 것
| # | 항목 | 기준 |
|---|---|---|
| 1 | **정답 정확성** | 원고 기준으로 정답이 맞는가, 복수 정답 여지는 없는가. **가장 중요하다.** |
| 2 | 근거 일치 | 참 진술·정답·해설의 사실이 인용문과 원고에서 확인되는가 |
| 3 | 함정의 타당성 | 거짓 보기가 원고 문장과 실제로 모순되는가(원고에 없을 뿐인 진술이 아닌가) |
| 4 | 이의 제기 여지 | 원고 밖 상식·실무로 다른 답을 우길 수 있는가. 단답형은 다른 표현을 써도 맞다고 할 여지 |
| 5 | **변별력** | 원고를 공부하지 않은 사람이 상식·어조·보기 형태만으로 정답을 고를 수 있는가 |
| 6 | 난이도 | `difficulty`가 실제 사고 수준과 맞는가(`exam_gen/spec/criteria.yaml`의 루브릭) |
| 7 | 지침 형식 | 질문형 발문, 문어체, 단답 조사 힌트, O 해설 반복, '원고'·쪽수 노출 |
| 8 | 지엽성 | 학습목표 관련 핵심 내용인가. 가상 사례의 인물·지점명, 인용 문헌 세부를 묻지 않는가 |
| 9 | 해설 | 해설만 읽어도 정답과 이유가 바로 보이는가 |
| 10 | 문장 | 맞춤법·주술 호응·용어 통일 |

## 5. 전체에 대해 볼 것
- 시험 1 대비 시험 2에서 '정답 단서'·지엽성·형식 문제가 실제로 줄었는가. 새로 생긴 문제는 없는가.
- 차시(절)별 분배가 분량에 비례하는가(30문항이라 쪽 단위 커버리지는 보지 않는다).
- 판단 포인트 중복.
- **300문항 본 출제 전에 꼭 고쳐야 할 규칙**이 있는가. 300문항으로 늘렸을 때 예상되는 위험(같은 원리 반복, 사례 중심 문항 쏠림 등).
