# 변경 내역

담당부서용 변경 기록입니다. 새 버전을 설치하면 무엇이 바뀌었는지 여기서 확인하세요.
설치된 버전은 대시보드 왼쪽 사이드바 맨 아래에 나옵니다. 문의할 때 버전을 함께 알려 주시면 빠르게 확인할 수 있습니다.

## v1.2.0 (2026-11-13) — 실사용 피드백(오류·수정 요청 11건) 반영
- **검수자 판단으로 승인**: 승인을 막는 사유가 무엇이든, 검수자가 사유를 확인하고 책임지고 승인할 수 있습니다(확인 체크·이름·메모). 엑셀 '검증 메모'와 품질 리포트에 표시됩니다.
- **보류**: 일단 두고 나중에 판단할 문항을 '보류'(중복 의심·내용 확인·기타 + 메모)로 둡니다. 출력할 때 포함 여부를 고르고, 엑셀에 연한 보라 행으로 표시됩니다.
- **난이도 판정 차이는 참고만**: AI 난이도 판정이 출제 난이도와 달라도 승인을 막지 않습니다.
- **단답형 근거 대조**: 유사답변이 근거 인용문에 있어도 통과하고, 맞지 않으면 무엇이 안 맞는지 보여 줍니다.
- **검사 이름 표시**: 'G2' 대신 '근거 대조(G2)'처럼 이름과 설명을 보여 주고, 같은 사유는 한 번만 표시합니다.
- **'1페이지 보고'처럼 원고에 있는 용어**는 쪽수 노출 규칙에 걸리지 않습니다.
- **수정 메모**가 다음 문항에 남던 오류를 고쳤습니다.
- **엑셀**: C열을 '출처 페이지'로 보이게 하고, 문항ID(R열)·출제 회차(S열)를 추가했습니다.
- **기출문제 등록**: 이 프로그램에서 내려받은 엑셀을 같은 프로젝트에 올리면 이미 있는 문항은 건너뜁니다. 이미 등록된 같은 문항은 버튼 하나로 지우고 다시 확인합니다. 기출을 저장하면 이미 만든 문항과 바로 비교합니다.
- **출제 옵션**: 난이도 '목표 · 출제 지시 · 예상 판정'을 한 표로 보여 줍니다. 추가 출제는 '총 수량 + 난이도 %' 하나로 통일했습니다. 페이지 재출제는 문항 수만 넣으면 문항이 없는 페이지에 자동으로 배정합니다.
- **오류 수정**: 기출 파일을 지운 뒤 출제하면 기존 문항을 덮어쓰던 오류, 객관식 기출을 먼저 올린 뒤 원고를 등록하면 나던 오류를 고쳤습니다.
- 업데이트 후 검수 화면을 처음 열면, 승인 전 문항을 바뀐 기준으로 한 번 다시 확인합니다(AI 사용 없음).

## v1.1.0 (2026-11-06) — v1.0.0 설치 피드백 반영
- **계정 확인**: 처음 실행하거나 Claude 계정이 바뀌면 "이 PC는 ○○ 계정으로 출제합니다" 확인 창이 뜹니다.
- **검수 완료 알림**: 남은 문항을 모두 처리하면 완료 창이 뜹니다. 검수가 남은 채 출력 화면에 들어오면 알림 창이 뜹니다.
- **엑셀**: 양식 칸 오른쪽 Q열에 난이도를 표시합니다(담당자 판정 우선).
- **원고 근거 새 창**에 해설도 함께 보입니다.
- **급할 때 수정 후 AI 재검증 없이 승인**: 고친 문항을 담당자가 직접 확인하고 바로 승인합니다(문항마다 확인 체크·검수자 이름). 'AI 검증 생략' 대기열에 남아 나중에 한꺼번에 검증하고, 출력 화면에 "아직 AI 검증 전 N문항" 안내가 보입니다. 버튼은 AI 설정 → 검수 설정에서 숨길 수 있습니다.
- **중지 버튼**: 출제 진행 화면의 중지를 진행률 옆으로 옮겼고, 품질 리포트의 '생략한 AI 검증 실행'도 뒤에서 실행되며 중지할 수 있습니다.

## v1.0.0 (2026-11-06) — 실사용 시작 버전
- **검수 화면**: 왼쪽 문항 목록 · 가운데 문항 · 오른쪽 원고 근거를 한 화면에 나란히 봅니다.
  - 보기(진술·정답)마다 바로 아래에 근거 인용문이 붙습니다(노랑 = 참 진술 근거, 파랑 = 함정 원문).
  - 원고 근거는 아래로 스크롤해도 화면에 붙어 있습니다.
  - 이전·다음 버튼은 문항 목록 바로 아래에 있습니다.
  - **원고 근거를 새 창으로 보기**: 듀얼 모니터에서 원고 근거를 다른 창에 크게 띄우고, 검수에서 문항을 바꾸면 따라 바뀝니다.
- **출제 옵션**: 문항 수를 먼저 정하고 → 난이도·유형 비율 → 페이지 배분 순서로 바꿨습니다. 비율마다 몇 문항인지 표시됩니다.
- **원고 등록**
  - 차시·출제 제외 범위를 쪽 번호 입력(Enter)으로 정합니다.
  - 원고를 올리면 본문의 장·절 제목으로 차시를 자동으로 나눠 둡니다.
  - 제외 이유(자동·직접)를 표시합니다.
  - 여러 파일은 이름순으로 등록하고, 등록 후 순서를 바꿀 수 있습니다.
- **난이도 기준**: 공통 기준과 별도로 과정(프로젝트)마다 전용 기준을 둘 수 있습니다.
- **AI 설정**: 로그인한 Claude 계정과 요금제를 보여 주고, 화면에서 로그아웃·다른 계정으로 로그인할 수 있습니다.
- **출제 중 자동 절전 막기**, 출제 토큰 사용량 기록, 사내 LiteLLM 모델 목록 불러오기
- 업데이트 후 처음 실행할 때 출제 데이터를 자동으로 백업합니다(프로젝트 관리 → 백업에서 되돌리기).
