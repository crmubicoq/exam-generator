# 01. 요구사항 및 배경

## 1. 요청 내용 (2026-10-20, 관련 부서)
- 원고(교재)를 첨부하면 **출제자의 옵션에 따라 문항을 자동 출제**하는 솔루션
- 에이전트 활용
- 지금까지 claude.ai 대화방에서 정립한 출제 방식·규칙·산출물 형식을 **그대로 포함**

## 3. 지금 방식(claude.ai 프로젝트)의 한계 → 솔루션화가 필요한 이유
- **재현성**: 같은 가이드를 줘도 대화마다 결과 품질이 흔들림 (원예 때 근거PDF를 4번 다시 만듦)
- **결정적 작업을 LLM이 매번 즉석 코딩**: 페이지 매핑·분포 계산·하이라이트는 코드로 고정해야 함
- **분포 편향이 끝나고서야 발견**: 정답 ① 편중, 함정 ㄱ 0회, 긴 보기=정답 회피 19% 등
- **사용자 의존**: 프롬프트·컨펌 흐름을 사람이 기억해야 함
- **대화 컨텍스트 한계**: 30문항 + 대용량 PDF 작업 중 대화가 여러 번 압축됨

## 4. 성공 기준
1. 원예기능사 교재 + 기출 Excel + 시나리오 B 옵션으로 실행 시, 기존 납품본과 **같은 형식·같은 검증 수준**의 산출물 4종이 나온다
2. 근거 자동 매칭률 80% 이상, 실패 문항은 리포트에 "수동 확인"으로 표시
3. 분포 기준(정답·함정·패턴·긴 보기 회피)을 생성 단계에서 통제해 사후 대량 수정이 없다
4. 출제자가 옵션만 고르면 되고, 프롬프트를 외울 필요가 없다

## 5. 범위
- **포함(MVP)**: 4지선다(ㄱㄴㄷㄹ 조합형), 단답형, 선다→단답 변환, 근거PDF, 검증 리포트, 거래처 메일 초안
- **확장 후보**: OX형(기획안 v3.0에는 있음, E-TEST에선 제외), 3/5지선다, 다권 교재, 웹 UI, 기출 DB 누적
