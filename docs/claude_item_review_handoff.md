- 확정적인 정답 오류는 발견하지 못했다.
- 재출제본: **높음 3개·중간 1개·문제없음 8개**.

- 변별력 평가는 수험자 실험 결과가 아니라 문항 구조를 바탕으로 한 전문가 판단·추정이다.

K00012의 **G5 수정안도 같은 빈도 편향을 남기므로 그대로 적용하면 안 된다.**

검토 가능한 대체 보기:

```text
① ㄱ, ㄴ, ㄷ
② ㄱ, ㄴ, ㄹ  ← 정답
③ ㄴ, ㄹ
④ ㄱ, ㄷ
```

이 경우 빈도는 ㄱ3·ㄴ3·ㄷ2·ㄹ2다. 보기 수정 후 지름길과 난이도를 다시 확인해야 한다.

나머지 **K00001·02·03·04·06·08·10·11은 내용상 무수정 사용 가능**으로 판단했다. 사람 승인(G7)은 별도다.

## 3. 자동 품질 등급에 대한 판단

재출제본의 자동 ‘변별력 D, 67%’는 G5 경고 8건을 집계한 수치다.

- 강한 변별력 결함: **K00005·07·09, 3/12=25%**.
- 추가적인 보기 구성 결함: **K00012**.
- 따라서 경고 8건 중 실제 수정 필요는 **4건**으로 판단했다.
- K00001은 유동화 개념을 확인하는 ‘하’ 문항으로 허용 가능하다.
- K00002는 대비 문장 구조만으로 정답이 결정되지 않는다.
- K00008은 설명을 보고 용어를 회상하는 ‘하’ 문항으로 허용 가능하다.
- K00010은 ‘설명의 이중화’의 대상·역할을 구분하는 ‘중’ 문항으로 볼 수 있다.
- **K00006·08은 실제로 ‘하’가 맞고, DB도 이미 ‘하’로 재분류되어 있다.** 목표가 ‘중’이었다는 이유로 현재 표시 오류로 다시 세지 않는다.

## 5. 규칙·코드 개선 우선순위

1. **거짓 보기 검증 강화**

   “원고의 어떤 문장과 어떤 관계로 모순되는가”를 확인한다. 예시 교환이나 비배타적 개념 교환만으로 거짓을 만들지 않는다.

2. **`choice_builder.py` 빈도 단서 검사 추가**

   현재 `shortcut_problems()`의 지름길 검사에 라벨 빈도 검사를 추가한다. G5가 제안한 수정 보기에도 재검사를 적용한다.

3. **`quality_report.py` 경고 집계 구분**

   상식적인 참 진술, 경미한 형식 차이, 정답 결정 단서를 같은 ‘변별력 결함’으로 합산하지 않는다. 자동 등급은 실측 변별도가 아니라 경고 집계임을 표시한다.

4. **난이도 평가 기준 유지·보강**

   인용 페이지 수나 문장 길이가 아니라, 정답 선택에 필요한 최소 판단 과정으로 평가한다. 목표 난이도와 재분류된 실제 난이도를 구분한다.

5. **최종 풀 단위 검수 추가**

   판단 포인트 중복, 단답형 허용 답안, O 해설 반복을 최종 선정 단계에서 함께 검사한다.

## 6. 확인된 개선 사항과 남은 과제

현재 형식 개선은 확인됐다. 비질문형 선다 발문과 ‘원고’ 노출은 두 Claude 프로젝트 모두 0건이다. 개선본은 26쪽 전체를 다루며 유형·정답 위치·O/X 분포도 대체로 양호하다.

**남은 핵심은 함정의 논리적 타당성, 보기 단서, 고난도 부족**이다.
