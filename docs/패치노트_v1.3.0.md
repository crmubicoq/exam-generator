# 평가문항 출제도구 v1.3.0 업데이트 안내

2차로 주신 '오류 및 수정 요청' 3건을 반영했습니다. 업데이트해도 출제 데이터는 그대로 유지되고, 처음 실행할 때 자동으로 백업됩니다.

## 업데이트 방법
1. 프로그램을 끕니다(검은 창 닫기).
2. `출제도구_v1.3.0_프로그램만.zip`을 지금 쓰는 `출제도구` 폴더가 **들어 있는 곳**에 풉니다.
   - 예: 프로그램이 `D:\출제도구\`에 있으면 `D:\`에 풉니다.
   - "파일을 덮어쓰시겠습니까?"가 나오면 **모두 덮어쓰기**를 고릅니다.
   - ZIP 안이 `출제도구` 폴더 하나로 묶여 있습니다. 그래서 `출제도구` 폴더 **안에서** 풀면 `출제도구\출제도구\`처럼 폴더가 하나 더 생기고, 예전 버전이 그대로 실행됩니다. 이때는 안쪽에 생긴 `출제도구` 폴더를 지우고 한 단계 위에서 다시 풉니다.
3. `실행.bat`으로 다시 켭니다. 왼쪽 사이드바 맨 아래에 **v1.3.0**이 보이면 완료입니다.
   - 출제 데이터(`projects`)·백업·AI 설정·Claude 로그인은 ZIP에 들어 있지 않아 그대로 남습니다.

## 바뀐 점

### 1. 수정 메모가 남아 있습니다 (요청 1)
- '수정 저장'을 누르면 수정 메모가 **문항에 보관**됩니다. 다른 탭(보류·승인·자동통과 등)에 다녀와도 메모 칸에 그대로 보입니다.
- 문항 위쪽에도 **'수정 메모'**로 표시되어 '문항 수정'을 펼치지 않아도 볼 수 있습니다.
- 메모만 고치고 저장하면 **문항 상태는 바뀌지 않습니다.** 메모를 지우려면 칸을 비우고 저장합니다.
- 업데이트 전에 적은 메모도 그 문항의 마지막 메모가 메모 칸과 문항 위쪽에 나옵니다.

### 2. 일괄 승인은 '자동통과'·'전체' 탭에서만 (요청 2)
- 일괄 승인은 경고가 없는 '자동통과' 문항에만 적용되므로, **'자동통과'와 '전체' 탭에서만** 보입니다.

### 3. 출력 문항 순서: 문항ID 순 (요청 3)
- 엑셀이 **문항ID 오름차순**(K00001, K00002 …)으로 나옵니다. 추가 출제분은 뒤에 모입니다.
- 출력 화면의 **'문항 순서'**에서 예전 방식인 **양식 순**(차시 → 유형 → 원고 쪽)도 고를 수 있습니다.
- 문항번호(D열)도 이 순서로 매기고, 근거PDF·시험지도 같은 순서를 씁니다.

### 그 밖의 개선·오류 수정
- **API 요금 방지**: PC에 Anthropic API 키 환경변수가 설정돼 있어도, Claude 구독 로그인으로 출제할 때는 그 키를 쓰지 않습니다(구독 사용량만 씁니다). 이런 PC에서는 AI 설정의 Claude 계정 칸에 안내가 나옵니다.
- 메모만 저장해도 자동통과 문항이 '확인 필요'로 옮겨지고 AI 검증 사유가 지워지던 오류를 고쳤습니다.
- 이의신청 조회에서, 출력한 뒤 크게 고친 문항을 **출력 당시 문장**으로 검색하면 찾지 못하던 오류를 고쳤습니다.
