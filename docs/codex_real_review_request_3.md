## 3. 시험 2 → 3에서 바꾼 규칙
1. **함정 판정(traps)**: 검수 AI가 거짓 보기마다 contradiction/compatible/not_stated/condition_missing을 판정하고, contradiction이 아니면 탈락. 시험 3에서는 22개 거짓 대상이 모두 contradiction으로 판정되어 이 사유의 탈락은 0건이었다.
2. **차시별 먼저 배분**(분량 비례) + 차시 안 페이지 순서대로 고르게: 3·6·10·6·5.
3. 보기 설계: 확인 경로·시점·역할·적용 조건으로 보기를 나누고, 과잉 확인·과잉 차단도 오답이 될 수 있게 함.
4. 단답형: 정답어가 빈칸 밖 지문에 나오면 탈락(코드), 서술 속 표현은 빈칸으로 내지 않게(프롬프트).
5. 검수 AI의 정답 단서 판정 기준 보정(배제되는 보기와 이유 명시, 기초 용어 문항 구분), 법령 문항의 법령명·예외·책임 조건 점검.
6. 시의성 표시(기관명·법령·금액·전화번호·날짜) — 경고만, 외부 확인 없음.

## 4. 특히 판정해 달라
- (a) **함정 판정이 실제로 믿을 만한가**: 22개 거짓 대상 중 원고와 동시에 성립할 수 있거나 조건이 부족한 것이 있는가. 검수 AI가 모두 contradiction으로 판정한 것이 과신(고무도장)인지.
- (b) 시험 2 대비 **정답 단서**(상식·어조·말뜻으로 풀림)가 실제로 줄었는가. 검수 AI 지적 12건 중 타당한 것.
- (c) **같은 원리 반복**: Claude는 K00005·K00006·K00007이 모두 '상대가 준 정보로는 독립 확인이 안 된다'를 묻는다고 본다. 다른 반복이 있는가.
- (d) 단답형 K00002('조합'), K00023('모든 분께 똑같이')처럼 용어가 아닌 말을 빈칸으로 낸 문항의 처리.
- (e) **300문항 출제 판단**: 진행 가능 / 규칙 수정 후 진행 / 보류, 그리고 진행 전에 꼭 고칠 것.
