노트북 설치 안내

작업 PC의 평가문항 자동 출제 도구를 노트북으로 옮겨, 담당자 앞에서 실제 출제까지 시연하기 위한 순서입니다. 처음 한 번은 30분 정도 걸립니다.

1작업 PC에서 데이터 묶기 작업 PC

  1. 프로그램 폴더에서 데이터_내보내기.bat을 두 번 클릭합니다.
  2. 바탕화면에 출제도구_이전데이터_날짜.zip이 생깁니다. 원고와 출제 결과(프로젝트)가 들어 있습니다.
  3. 이 ZIP을 USB로 노트북에 옮깁니다.
ZIP에는 납품 원고가 들어 있습니다. 메일·외부 공유 드라이브·GitHub에 올리지 마세요.

2프로그램 받기 노트북

  1. GitHub 저장소 crmubicoq/exam-generator에서 Code → Download ZIP으로 받거나, Git이 있으면 git clone으로 받습니다.
  2. 압축을 D:\ExamGenerator처럼 짧고 단순한 경로에 풉니다. 바탕화면이나 OneDrive 폴더는 피합니다.

3Python 설치 노트북

  1. python.org에서 Python 3.12를 내려받아 설치합니다.
  2. 설치 첫 화면 아래의 "Add python.exe to PATH"에 꼭 체크합니다.
이미 Python 3.10 이상이 있으면 건너뜁니다. 설치 프로그램이 다음 단계에서 자동으로 확인합니다.

4도구 설치 노트북

  1. 프로그램 폴더의 setup.bat을 두 번 클릭합니다. 인터넷이 필요하고 처음에는 몇 분 걸립니다.
  2. 마지막에 설치 점검 결과가 나옵니다. [ 필요 ] 항목이 있으면 안내대로 처리한 뒤 다시 실행합니다.

5데이터 가져오기 노트북

  1. 1단계에서 만든 ZIP을 노트북 바탕화면이나 프로그램 폴더에 둡니다.
  2. 데이터_가져오기.bat을 두 번 클릭합니다. 가장 최근 ZIP을 찾아 원고와 프로젝트를 제자리에 풉니다.
  3. 노트북에 이미 데이터가 있으면 지우지 않고 projects_이전백업_날짜 폴더로 옮겨 둡니다.

6Claude 로그인 (실제 출제 시연용) 노트북

  1. Claude_로그인.bat을 두 번 클릭합니다.
  2. 열린 화면에서 /login을 입력하고 Enter → 브라우저에서 작업 PC와 같은 Claude 계정으로 로그인·승인합니다.
  3. 로그인되면 /exit로 닫습니다. 자동으로 Claude를 한 번 호출해 로그인을 확인합니다.
이미 만든 결과만 보여 줄 때는 로그인이 필요 없습니다. Claude Code를 따로 설치하지 않아도 됩니다(도구 안에 포함).

7실행 노트북

  1. run.bat을 두 번 클릭하면 브라우저에 대시보드가 열립니다(http://localhost:8620).
  2. 까만 실행 창은 닫지 말고 둡니다. 창을 닫으면 프로그램이 종료됩니다.
  3. 사이드바에서 시연할 프로젝트를 고릅니다. 마지막에 작업한 프로젝트가 자동으로 선택됩니다.

8시연 전 확인 목록

확인방법
원고·프로젝트가 보이는가사이드바 프로젝트 목록, 홈 화면 문항 수
검수 화면에서 원고 근거가 보이는가검수 → '원고 근거' 탭에 하이라이트
엑셀·근거PDF가 만들어지는가출력 → 세 가지 만들기 버튼
Claude 출제가 되는가사이드바 LLM 설정 → '연결·로그인 확인'. 시연 전날 5문항 정도 시험 출제
인터넷회의실 와이파이가 불안정하면 휴대폰 핫스팟 준비
시연 당일에는 큰 출제를 미리 돌리지 마세요. 구독 사용 한도에 걸리면 출제가 잠시 멈춥니다. 현장 시연은 5~10문항(2~3분)을 권합니다.
