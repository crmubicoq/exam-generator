# 05. 데이터 스키마

## 1. q_data.json (문항 데이터 — 파이프라인의 중심)
v8 가이드 스키마 + 원예 회차 실제 필드(rationale/wrong)를 통합. 생성·검증·출력 모듈 모두 이 형식만 읽고 쓴다.
```json
{
  "project": "2026 E-TEST 원예기능사",
  "version": "1",
  "options_ref": "options.json",
  "page_mapping": {"rule": "pdf_idx = book_page + offset", "offset": 0, "exceptions": {}},
  "questions": [
    {
      "no": 1,
      "slot": {"chapter": "채소", "pattern": "A", "answer_pos": "③", "trap_labels": ["ㄹ"],
               "difficulty": "최상", "discrimination": "변별 핵심", "type": "mcq"},
      "stem": "채소의 번식에 관한 설명으로 옳은 것을 모두 고른 것은?",
      "statements": [
        {"label": "ㄱ", "text": "...", "is_correct": true,
         "source_page": 15, "evidence_text": "원문 인용", "trap_type": null},
        {"label": "ㄹ", "text": "...", "is_correct": false,
         "source_page": 16, "evidence_text": "원문 인용", "trap_type": "정반대",
         "trap_note": "'덩이뿌리'를 '줄기'로 바꾼 함정"}
      ],
      "choices": [
        {"no": "①", "labels": ["ㄱ","ㄴ"]}, {"no": "②", "labels": ["ㄴ","ㄷ","ㄹ"]},
        {"no": "③", "labels": ["ㄱ","ㄴ","ㄷ"]}, {"no": "④", "labels": ["ㄷ"]}
      ],
      "answer": "③",
      "explanation": "...",
      "short_answer": null,
      "validation": {
        "evidence_level": "L2", "expression_ok": true,
        "dedup": {"result": "pass", "max_similar_previous": "기출 045", "score": 0.61},
        "quality": {"stem_clarity": true, "answer_uniqueness": true, "wrong_clarity": true,
```

## 2. statement_locations.json (근거 PDF용)
```json
{ "1": { "statements": [
  {"label": "ㄱ", "type": "correct", "locations": [{"page": 15, "line_start": 5, "line_end": 7}]},
  {"label": "ㄹ", "type": "wrong",   "locations": [{"page": 16, "line_start": 12, "line_end": 14}]}
]}}
```
- `page` = PDF 0-based index (책 페이지 아님). 원예 실측: 86개 진술 / 112개 위치 / 298줄 하이라이트
