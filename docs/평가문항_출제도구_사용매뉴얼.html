1. 설치와 첫 실행

설치 (PC마다 처음 한 번)

  1. 받은 출제도구_휴대용_날짜.zip을 마우스 오른쪽 버튼 → 속성 → 아래쪽 '차단 해제'에 체크하고 확인을 누릅니다(보이지 않으면 건너뜁니다).
  2. 짧은 경로에 압축을 풉니다. 예: C:\출제도구 또는 D:\출제도구. 바탕화면·OneDrive 폴더나 긴 경로는 피합니다.
  3. Python 등 다른 프로그램은 설치하지 않아도 됩니다(패키지 안에 들어 있습니다). setup.bat은 개발용이라 실행하지 않습니다.

Claude 로그인 (PC마다 처음 한 번)

  1. 프로그램 폴더의 Claude_로그인.bat을 두 번 클릭합니다.
  2. 열린 화면에서 /login을 입력하고 Enter를 누릅니다.
  3. 브라우저가 열리면 회사 Claude 계정으로 로그인하고 승인합니다.
  4. 로그인되었다는 메시지가 나오면 /exit를 입력해 닫습니다. 스크립트가 Claude를 한 번 호출해 연결을 확인합니다.

로그인 정보는 그 PC의 윈도우 사용자 계정에 저장되고, 이 프로그램은 저장하지 않습니다. 같은 계정을 여러 PC에서 쓰면 사용 한도를 함께 씁니다.

실행 (매번)

  1. run.bat을 두 번 클릭합니다. 검은 창이 뜨고 잠시 뒤 브라우저에 프로그램 화면이 열립니다(주소 http://localhost:8620).
  2. 검은 창은 닫지 마세요. 검은 창이 프로그램 본체입니다. 닫으면 프로그램이 꺼지고, 출제 중이었다면 출제도 멈춥니다. 최소화는 괜찮습니다.
  3. 브라우저 탭은 닫았다가 다시 열어도 됩니다(위 주소를 입력). 마지막에 작업한 프로젝트가 그대로 선택됩니다.

2. 화면 구성

왼쪽 사이드바에 위에서부터 다음이 있습니다.

영역내용
프로젝트작업할 과정을 고르는 목록과 새 프로젝트 만들기. 목록은 최근에 만든 순서입니다.

3. 프로젝트 만들기

프로젝트는 원고(교재) 하나에 하나입니다. 같은 과정을 여러 번 출제하면 구분 메모로 나눕니다.

  1. 사이드바 새 프로젝트를 펼칩니다.
  2. 과정명(필수)과 구분 메모(예: 2026 상반기 · 300문항 본출제)를 넣고 만들기를 누릅니다. 같은 이름은 만들 수 없습니다.
  3. 만들면 목록이 새 프로젝트로 바뀌고 원고 등록 화면으로 바로 넘어갑니다.

4. 원고 등록

화면 안에서 ①~④ 순서대로 진행합니다. 단계마다 '완료 / 할 일 / 선택' 표시가 붙습니다.

① 원고 파일 올리기

  • PDF·PPTX·DOCX·HWP를 올리고 파일 등록을 누릅니다. 원고가 여러 파일이면 단원 순서대로 올립니다.
  • 올리면 본문에서 '제1절', '2장', 'Chapter 3', '4차시'처럼 번호 붙은 큰 제목을 찾아 차시를 미리 나눠 둡니다(③에서 확인).
  • 같은 이름의 파일은 다시 등록되지 않습니다. 수정본은 화면 맨 아래 새 판으로 교체를 씁니다.
  • HWP는 PC의 한글 프로그램으로 PDF 변환을 시도합니다. 안 되면 한글에서 PDF로 저장해 올립니다.

② 쪽수 확정 (필수)

  • 원고에 인쇄된 쪽 번호를 자동으로 찾습니다. 오른쪽에 보이는 머리말·꼬리말 그림과 비교해 맞으면 이 쪽수로 확정을 누릅니다.
  • 엑셀의 쪽수 칸과 근거 PDF에 이 쪽수가 쓰입니다. 확정하기 전에는 출제를 시작할 수 없습니다.
  • 쪽수가 다르면 '파일 첫 쪽의 원고 쪽수'를 고쳐 확정합니다.

③ 차시 나누기·출제 제외 페이지

용어뜻
차시교육 과정의 회차·단원입니다(예: 1차시 = 1장). 차시마다 문항 수를 분량에 맞춰 먼저 나누므로 단원마다 고르게 출제됩니다. 원고가 한 단원이면 모두 1차시로 두어도 됩니다.
원고 쪽수원고에 인쇄된 쪽 번호(②에서 확정한 값). 엑셀·근거 PDF에 쓰입니다.
순번파일을 첫 장부터 1, 2, 3…으로 센 번호입니다. 표지처럼 쪽 번호가 없는 장도 셉니다.
출제 제외표지·목차·부록·참고문헌처럼 문항을 내지 않을 페이지입니다.
제외 이유'자동: 글자가 적음', '자동: 목차 페이지'는 프로그램이 뺀 것, '직접 제외'는 사람이 뺀 것입니다.
  1. 차시 자동 제안 표에서 찾은 제목과 차시별 시작·끝 쪽을 확인합니다. 지금 설정과 다르면 이 안으로 다시 나누기를 누릅니다.
  2. 쪽 범위로 한꺼번에 지정: 할 일(차시 지정 / 출제 제외 / 제외 풀기)을 고르고, 원고 쪽수로 시작 쪽·끝 쪽을 고른 뒤 적용을 누릅니다. 바로 저장됩니다. 예: 머리말·목차를 빼려면 '출제 제외'로 그 쪽 범위를 적용합니다.
  3. 한두 쪽만 고칠 때는 아래 페이지별 설정 표에서 차시·제외를 바꾸고 페이지 설정 저장을 누릅니다.

이미 출제한 뒤 차시를 바꾸면 문항의 차시(엑셀 A열)도 함께 바뀝니다.

④ 과정 정보 (권장)

과목/주제명과 학습목표를 넣습니다. 학습목표는 AI가 '중요한 내용인지' 판단하는 기준이 됩니다. 원고에 학습목표가 있으면 후보가 보입니다.

원고가 수정되었을 때

  1. 화면 맨 아래 새 판으로 교체에서 수정본을 올립니다. 쪽이 밀린 문항은 쪽수가 자동으로 고쳐지고, 근거 문장이 바뀌거나 사라진 문항만 '원고 변경'으로 표시됩니다(AI 사용 없음).
  2. 원고가 더 바뀌지 않으면 변경 문항 일괄 처리를 누릅니다. 예상 AI 호출 수를 먼저 보여 주고, 바뀐 문항은 바뀐 부분만 고치고 사라진 문항은 같은 조건으로 다시 출제합니다.

5. 기출문제 등록 (선택)

  • 이미 시험에 쓴 문항을 올리면 새로 출제할 때 같은 내용을 피합니다. 기출이 없으면 건너뜁니다. 원고를 먼저 등록한 뒤 진행합니다.
  • 제출 양식 엑셀은 그대로 읽습니다. 다른 형식의 엑셀·CSV·한글·워드·PDF는 AI가 표준 형식으로 바꿉니다(예상 호출 수를 먼저 보여 줍니다).
  • 미리보기 표에서 확인·수정한 뒤 저장합니다. 기출문제는 검수·출력에 들어가지 않습니다.

6. 출제 옵션

  1. 출제 종류: 최초 출제(처음) / 추가 출제(기존 문항과 겹치지 않게 더) / 페이지 재출제(문항이 없거나 적은 페이지만).
  2. 난이도 비율(최상·상·중·하, 합계 100)과 유형 비율(선다형·진위형·단답형, 합계 100)을 정합니다. 칸 아래에 몇 문항인지가 표시됩니다.
  3. 세부 옵션: 선다형 '옳은 것 고르기' 비율(기본 20%, 옳지 않은 것 : 옳은 것 = 8 : 2), 조합형(ㄱㄴㄷㄹ) 비율, 재출제 횟수, 배점, 문항번호 방식, 난이도 보정 출제, 빠른 출제. 각 옵션 아래에 설명과 문항 수가 나옵니다.
  4. 문항 수와 여유분: 최초 출제는 '필요 문항 수'와 '여유분(기본 15%)'을 넣습니다. 여유분은 검수에서 지울 문항에 대비해 조금 더 출제하는 것으로, 출력할 때 '최종 문항 자동 선정'이 필요한 수만 고릅니다. 예: 300문항 + 15% = 345문항 출제.
  5. 추가 출제는 '난이도별 수량'으로 각 난이도 문항 수를 직접 넣거나, '총 수량 + 난이도 %'로 넣습니다.
  6. 출제 전 점검에서 쪽수 확정, 차시, 학습목표, 난이도 기준, 사용할 AI, 예상 시간을 확인합니다. 문제가 있으면 빨간 안내가 나옵니다.
  7. 확인 체크를 한 뒤 출제 시작을 누릅니다. '옵션만 저장'은 출제하지 않고 설정만 남깁니다.

난이도 보정 출제(기본 켬): AI 검수는 출제 의도보다 난이도를 낮게 판정하는 경향이 있습니다. 켜 두면 어려운 문항을 조금 더 배정해 검수 판정 기준으로 목표 비율에 가깝게 맞춥니다. 화면에 '출제 지시 난이도'와 '예상 판정'이 함께 나옵니다.

빠른 출제(급할 때만): AI 독립 풀이·AI 검수를 생략해 시간이 약 1/3로 줄어듭니다. 형식·근거 대조·규칙·중복 검사는 그대로 합니다. 생략한 검증은 나중에 품질 리포트에서 한꺼번에 실행할 수 있습니다.

7. 출제 진행

  • 진행률, 통과·경고·수동확인 수, 검증 단계별 탈락 수, 예상 남은 시간, AI 호출 수가 실시간으로 바뀝니다.
  • 출제하는 동안 다른 화면을 보거나 다른 프로그램을 써도 됩니다. 브라우저 탭을 닫아도 출제는 계속됩니다.
  • 출제 중에는 프로그램이 윈도우 자동 절전을 막습니다. 다만 검은 창을 닫거나, 노트북 덮개를 닫거나, 직접 절전·종료하면 멈춥니다.
  • 멈추거나 인터넷이 끊겨도 이어서 출제로 남은 부분만 계속합니다. AI 사용 한도에 걸리면 기다렸다가 자동으로 다시 시도합니다.
  • 끝나면 윈도우 알림이 뜨고(PC 알림 설정에 따라 안 보일 수 있음), 프로젝트가 자동 백업됩니다.
규모예상 시간(Claude 구독, 난이도 보정 출제 켬)
시험 삼아 5~10문항약 3~7분
30문항약 15분
100문항 (+여유 15%)약 1시간 5분
300문항 (+여유 15%)약 3시간 15분 · AI 호출 약 1,700회

시간은 대부분 AI 응답을 기다리는 시간이라 PC 사양과는 거의 관계없고, 인터넷과 AI 서버 상태에 따라 달라집니다. 처음에는 30문항 정도로 흐름을 익힌 뒤, 본출제는 PC를 오래 켜 둘 수 있을 때 시작하세요.

8. 검수

  1. 화면 위쪽 대기열에서 확인 필요(경고·수동확인)부터 봅니다. 유형·난이도·차시·쪽수·검색으로 좁혀 볼 수 있습니다.
  2. 왼쪽 목록에서 문항을 고르면 오른쪽에 탭이 나옵니다: 문항(시험지 형태) · 원고 근거(원고 페이지 위 하이라이트) · 검증 상세 · 이력.
  3. 원고 근거 색: 노란색 = 정답(옳은 진술)의 근거, 파란색 = 함정 보기가 바꾼 원래 문장.
  4. 화면 맨 위에 검수자 이름을 한 번 넣으면 기억합니다. 경고 내용을 읽고 문제없으면 승인을 누릅니다. 다음 문항으로 넘어갑니다.
  5. 고칠 내용이 있으면 문항 수정에서 고친 뒤 AI 재검증을 받아야 승인할 수 있습니다.
  6. 쓸 수 없는 문항은 사유를 적고 삭제합니다. 삭제한 문항은 복원할 수 있습니다.
  7. 담당자 판정 난이도(하·중·상·최상)를 누르면 그 문항의 난이도를 직접 정합니다. AI 판정보다 우선하고, 승인은 유지됩니다.
  8. 일괄 승인은 경고가 없는 '자동통과' 문항에만 적용됩니다.
경고는 '사람이 한 번 보라'는 뜻입니다. 정답 관련 지적과 이의 제기 여지 경고는 꼭 확인하세요. 자동 검증은 사람 검수를 대신하지 않습니다.

9. 출력

  1. 출력 대상을 고릅니다: 전체(검수 없이 — 탈락 문항은 엑셀에 연한 빨강으로 표시) / 자동 검증 통과 / 승인한 문항만(납품용) / 최종 선정 문항만.
  2. 최종 문항 자동 선정: 여유분까지 출제한 문항에서 목표 수만큼 난이도·유형·차시 목표에 맞춰 고릅니다. 같은 원리를 반복한 문항은 하나만, 경고가 큰 문항은 뒤로 미룹니다(AI 사용 없음).
  3. 출력 범위(전체 또는 특정 회차)를 고릅니다. 회차는 '출제 시작'을 한 번 누른 단위입니다.
  4. 엑셀, 문항별 근거 PDF, 원고 전체 근거 PDF, 시험지 PDF(검토·회의용)를 만들어 내려받습니다. 파일은 프로젝트 폴더의 exports에도 저장됩니다.
출력물내용
평가문항 엑셀제출 양식 그대로(4행부터). A 차시 · B 유형 · C 쪽수 · D 번호 · E 문제 · F~I 보기 · J 정답(단답형은 '정답 (유사답변: …)') · K 해설 · L 채점기준 · M 배점. 숨김 열에 문항키·난이도·근거 원문 등. '검증리포트' 시트에 분포·통계.
근거 PDF(문항별)문항마다 안내 페이지(발문·보기·정답·해설) + 근거 원고 페이지에 하이라이트와 라벨. 300문항이면 차시별 파일로 나눌 수 있습니다.
근거 PDF(원고 전체)원고 각 페이지에 그 페이지에서 나온 모든 문항 라벨 표시. 원고 전체에 고르게 출제됐는지 볼 때 씁니다.
시험지 PDF문항을 시험지 형태로. 정답·해설 포함/제외, 차시별 구분 선택.

출력할 때마다 '출력 이력'에 언제 어떤 파일을 몇 문항으로 만들었는지 남고, 예전 파일을 다시 받을 수 있습니다. 서비스 시스템에 문항을 올릴 때 문항키(엑셀 숨김 R열)를 함께 보관하면 이의신청 때 가장 빨리 찾을 수 있습니다.

10. 관리 메뉴

품질 리포트

  • 정답·이의 제기·출처·원고 전반·형식·변별력·난이도를 A~D 등급으로 보여 줍니다(A 납품 수준, D 재출제 권장). 문제 문항을 고르면 검수 화면에서 바로 열립니다.
  • 같은 원리 반복 묶음마다 남길 문항을 고르고 나머지를 삭제할 수 있습니다.
  • 등급은 AI 검수 경고를 센 값으로, 무엇을 먼저 볼지 정하는 데 씁니다.

난이도 기준

  • 하·중·상·최상을 무엇으로 나눌지 정합니다. AI가 이 기준으로 출제하고 난이도를 판정합니다.
  • 공통 기준은 모든 프로젝트가 씁니다. 과정마다 기준이 다르면 '고칠 기준'에서 '이 프로젝트 전용 기준'을 골라 따로 정합니다(공통 기준이 복사된 채로 열립니다). 전용 기준을 지우면 다시 공통 기준을 따릅니다.
  • 담당자가 확인한 기준이면 '확정'에 체크하고 확인자 이름을 넣어 저장합니다. 바꾼 기준은 이후 출제·AI 재검증부터 적용됩니다.

이의신청 조회

  • 문제 문장 일부, 문항키(예: K00012), 또는 출력 파일 + 문항번호로 모든 프로젝트에서 찾습니다.
  • 문항, 원고 근거, AI 독립 풀이·함정 판정 근거, 출력 이력을 한 화면에서 보고, 처리 결과를 기록한 뒤 이의신청 검토서 PDF를 만듭니다.

프로젝트 관리

  • 프로젝트별 만든 날, 마지막 수정, 원고, 문항 수, 출제 이력(회차별 AI·모델·호출 수·토큰·걸린 시간)을 봅니다.
  • 이름 바꾸기, 백업에서 되돌리기, 삭제(휴지통으로 이동, 되살리기 가능)를 합니다.

11. AI 설정

사이드바 맨 아래 AI 설정입니다. 기본값(Claude 구독 로그인 · Claude Opus 5.5)을 그대로 쓰면 됩니다.

  • 연결·로그인 확인: 로그인이 되어 있는지 확인합니다. 실패하면 Claude_로그인.bat을 다시 실행합니다.
  • 사내 LiteLLM을 쓸 때: 생성 공급자를 'LiteLLM'으로 고르고 주소와 API 키를 넣은 뒤 모델 목록 불러오기를 누르면 서버의 모델이 선택 목록에 나옵니다. 모델을 고르고 저장합니다. API 키는 윈도우 자격 증명 저장소에 보관됩니다.
  • 출제 속도 설정(한 번에 만드는 문항 수 8, 병렬 페이지 3)은 문항 품질과 관계없고 보통 그대로 둡니다.

13. 데이터 옮기기·백업·업데이트

  • 저장 위치: 원고와 출제 결과는 프로그램 폴더 안(projects)에만 저장됩니다. 출제할 때 해당 페이지 원문이 AI 서비스로 전송됩니다.
  • 자동 백업: 출제가 끝날 때, 원고를 교체하기 전, 프로젝트를 삭제하기 전에 프로그램 폴더의 '백업'에 자동으로 남습니다(프로젝트마다 최근 10개). 프로젝트 관리에서 되돌립니다.
  • 다른 PC로 옮기기: 데이터_내보내기.bat → 바탕화면에 ZIP 생성 → 새 PC에서 ZIP을 바탕화면이나 프로그램 폴더에 두고 데이터_가져오기.bat. ZIP에는 원고가 들어 있으니 메일·외부 공유 드라이브로 보내지 마세요.
  • 두 PC에서 같은 프로젝트를 동시에 고치지 마세요. 문항 데이터는 PC 사이에 자동으로 합쳐지지 않습니다. 한 과정은 한 PC에서 작업합니다.
  • 업데이트: 프로그램 수정본은 출제도구_프로그램만_날짜.zip으로 드립니다. 프로그램을 끄고(검은 창 닫기) 설치 폴더에 그대로 덮어쓰면 됩니다. 출제 데이터(projects)·백업·설정은 그대로 남습니다.
