# 07. 교훈과 함정 (같은 실수 반복 금지)

| # | 문제 | 원인 | 해결 / 솔루션 반영 |
|---|---|---|---|
| 1 | 근거PDF에 하이라이트가 하나도 없음 | 가이드에 "근거 PDF 추출본" 한 줄만 있어 페이지만 잘라 붙임 | 06 문서 코드로 고정, 하이라이트 0개 문항 = 실패 처리 |
| 2 | 키워드 search_for 매칭 실패 다발 | OCR PDF: "675nm"→"6 7 5 n m", "CO₂"→"Cᄋ2" | normalize + 누적 텍스트 매칭 |
| 3 | 키워드 단위 하이라이트가 페이지 전체에 번짐 | 3~5자 짧은 키워드가 여러 곳에 걸림 | 인용 시작 마커 기반 줄 범위 매칭, 10줄 초과 시 4줄 제한 |
| 4 | 페이지 매핑이 들쭉날쭉해 보임 | 실제 PDF는 일관(offset 0)인데 출처 기록 일부가 +1 | Phase 0에서 footer로 규칙 확정 + 출처 기록 시 매핑 규칙 강제 + ±1 fallback |
| 5 | 정답 ① 편중, 함정 ㄱ 0회 | 30문항을 다 만든 뒤 분포 확인 | 슬롯 사전 배정(planner) + 실시간 tracker |
| 6 | "가장 긴 보기 = 정답" 19% | 정답 보기가 늘 라벨 3개 | choice_builder가 회피 비율을 코드로 보장 |
| 7 | 패턴 A만 사용 | 4패턴 규칙이 출제 후 추가됨 | planner가 패턴을 슬롯에 배정 |
| 8 | 텍스트 파일 한글·이모지 깨짐 (Windows) | UTF-8 BOM 없음 + 이모지 | 텍스트 출력은 `utf-8-sig`, 산출물에 이모지 금지 |
| 9 | 대화 컨텍스트가 여러 번 압축됨 | 30문항 + 대형 PDF를 한 대화에서 처리 | 파이프라인은 단계별 JSON 파일로 상태 저장, 재개 가능하게 |
| 10 | 가이드의 검증 코드가 실제로는 동작 안 함 | 기출회피·품질 검증이 의사코드 | 구현 대상으로 명시, 원예 데이터로 테스트 |
| 11 | "PDF 원본 100% 일치" 비현실적 | OCR 오차 | L1~L4 차등 기준 |
| 12 | 표현 정확도 규칙이 v5 이후 약해짐 | 기획안 v3.0 규칙이 가이드로 옮겨지며 누락 | Validator expression 검사로 부활 |
