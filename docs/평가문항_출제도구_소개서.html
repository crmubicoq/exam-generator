평가문항 자동 출제 도구

교육 과정 원고를 올리면 지침에 맞는 평가문항을 원고 전체에 고르게 출제하고, 문항마다 원고의 어디에 근거가 있는지 표시하는 프로그램입니다. AI가 만든 문항은 여러 단계로 자동 검증한 뒤 담당자가 검수하고, 제출 양식 엑셀과 근거 PDF로 내보냅니다.

2. 왜 만들었나

  • 출제 시간 단축: 300문항 규모 출제를 사람이 직접 하면 며칠이 걸립니다. 이 도구는 출제·1차 검증을 약 3시간 15분에 끝내고, 담당자는 검수에 집중합니다.
  • 원고 전반 출제: 원고 분량에 맞춰 차시·페이지마다 문항 수를 먼저 나눈 뒤 출제하므로 특정 단원에 몰리지 않습니다.
  • 근거가 분명한 문항: 문항마다 정답 근거와 함정 원문을 원고 위에 색으로 표시합니다. 검수와 이의신청 대응이 빨라집니다.
  • 신뢰도: 문항 오류는 서비스 사고로 이어지므로, 자동 검증 6단계와 담당자 승인을 거친 문항만 납품용으로 내보냅니다.

3. 작업 흐름

단계하는 사람하는 일
① 원고 등록담당자PDF·PPT·워드·한글 원고를 올리고 인쇄된 쪽수를 확정합니다. 차시(단원)는 원고의 장·절 제목을 찾아 자동으로 나눠 두고, 담당자는 확인만 합니다.
② 기출문제 등록담당자(선택)이미 쓴 문항을 올리면 새로 출제할 때 같은 내용을 피합니다.
③ 출제 옵션담당자문항 수, 난이도·유형 비율을 정합니다. 비율마다 몇 문항인지, 예상 시간이 바로 보입니다.
④ 출제·자동 검증AI + 프로그램페이지마다 문항을 만들고 6단계로 검증합니다. 통과하지 못하면 자동으로 다시 출제합니다.
⑤ 검수담당자문항과 원고 근거를 나란히 보고 승인·수정·삭제합니다. 난이도를 직접 판정할 수도 있습니다.
⑥ 출력프로그램최종 문항 자동 선정, 제출 양식 엑셀, 근거 PDF, 시험지 PDF를 만듭니다.

6. 그 밖의 기능

  • 원고 개정 대응: 원고 새 판을 올리면 쪽이 바뀐 문항은 자동으로 쪽수를 고치고, 근거 문장이 바뀐 문항만 표시합니다. 원고가 확정되면 그 문항만 한 번에 고칩니다.
  • 이의신청 대응: 문제 문장 일부나 문항키로 모든 과정에서 문항을 찾아 원고 근거, 검증 기록, 출력 이력을 한 화면에서 보고, 검토서 PDF를 만듭니다.
  • 과정별 난이도 기준: 공통 기준과 별도로 과정마다 난이도 기준을 따로 정할 수 있습니다.
  • 품질 리포트: 정답·이의 제기·출처·원고 전반·형식·변별력·난이도를 등급으로 보여 주고 먼저 볼 문항을 알려 줍니다.
  • 안정성: 출제가 끝날 때 등 자동 백업, 중단되면 이어서 출제, 출제 중 PC 자동 절전 막기, 끝나면 윈도우 알림.

7. 알고 쓰셔야 할 한계

난이도가 목표 비율대로 나오지 않습니다. AI 검수는 출제 의도보다 낮게 판정하는 경향이 있습니다. 100문항 시험에서 최상은 0문항이었습니다. '난이도 보정 출제'로 상 문항은 목표에 가깝게 맞추지만, 최상과 중·하의 경계는 담당부서가 난이도 기준을 정해야 해결됩니다(9절).

자동 검증은 사람 검수를 대신하지 않습니다. 시험 출제에서 정답 오류는 걸러졌지만, 상식으로 정답이 보이는 보기나 이의 제기 여지가 있는 문항이 경고로 남습니다. 경고 문항은 담당자가 확인한 뒤 승인합니다.

사실 확인은 원고 기준입니다. 기관명·법령·금액처럼 바뀔 수 있는 내용이 든 문항에는 '시의성 확인' 표시만 하고, 인터넷으로 최신 여부를 확인하지는 않습니다.

8. 운영 방식

항목내용
설치PC마다 압축 파일을 풀어 쓰는 휴대용 패키지입니다(Python 등 별도 설치 없음). 담당부서 2명이 각자 PC에 설치합니다. 서버형(여러 사람이 브라우저로 접속)은 추후 검토합니다.
AI앞으로 1~2개월은 Claude 구독 계정(모델: Claude Opus 5.5)으로 출제합니다. 별도 청구는 없고 구독 사용 한도 안에서 씁니다. 사내 LiteLLM으로도 연결할 수 있게 준비되어 있습니다.
소요 시간300문항(여유 15% 포함 345문항) 약 3시간 15분, 100문항 약 1시간 5분, 30문항 약 15분. 출제 중에도 PC로 다른 작업을 할 수 있습니다.
비용(참고)구독 계정은 별도 비용이 없습니다. 회사 API 키 방식으로 바꾸면 실측 기준 문항당 약 0.6달러, 300문항 약 200달러로 추정합니다.
데이터 보안원고와 출제 결과는 각 PC 안에만 저장되고 자동 백업됩니다. 출제할 때는 해당 페이지 원문이 AI 서비스(Claude)로 전송됩니다.

9. 정해 주셔야 할 것

#항목내용
1난이도 기준받은 기준 문서에는 비율만 있고 하·중·상·최상의 정의가 없습니다. 지금은 교육 평가에서 널리 쓰는 인지 수준(하=기억, 중=이해, 상=적용, 최상=분석·종합)으로 만든 임시 기준안을 씁니다. 부서 기준이 있으면 프로그램에 넣어 확정합니다.
2최상 문항의 기준'자격시험형 실무 사례 문항'이면 최상으로 볼지, 판단이 두 단계 이상 이어져야 최상인지.
3AI 사용 방식운영 단계에서 구독 계정, 회사 API 키, 사내 LiteLLM 중 무엇을 쓸지. 원고를 어느 외부 AI 서비스까지 보내도 되는지(보안 정책).
4사용 계정담당자 2명이 Claude 계정을 1인 1개씩 쓸지, 하나를 같이 쓸지(같이 쓰면 사용 한도도 함께 줄어듭니다).
5서버형 전환 시점팀 서버에 올려 로그인해 쓰는 방식이 필요한지, 필요하면 시점.
