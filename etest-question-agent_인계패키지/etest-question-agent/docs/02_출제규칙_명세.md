# 02. 출제 규칙 명세 (스킬가이드 v8 통합본)

> 이 문서가 생성(Generator)·검증(Validator) 에이전트 프롬프트와 검증 코드의 기준이다.
> 원본: `reference/guides/AI문항출제_스킬가이드_v8.docx`, `AI_문항출제시스템_기획안.docx`

## 1. 문항 형식 (선다형: ㄱㄴㄷㄹ 조합형 4지선다)
- 발문 예: "~에 관한 설명으로 옳은 것을 모두 고른 것은?"
- 진술 4개(ㄱ·ㄴ·ㄷ·ㄹ) = 정답 진술 + 함정 진술
- 보기 ①~④ = 라벨 조합

## 2. 진술 패턴 4종
| 패턴 | 구성 | 기본 비율(시나리오 B) | 용도 |
|---|---|---|---|
| A | 정답 3 + 함정 1 | 50% | 기본형 |
| B | 정답 2 + 함정 2 | 30% | 변별형 |
| C | 정답 1 + 함정 3 | 10% | 극상 변별 (변별 핵심 우선 배치) |
| D | 정답 4 + 함정 0 | 10% | 함정 케이스 (전체 라벨 보기 예외 허용) |

※ 원예 회차는 실제로 패턴 A 위주로만 출제됨 → 4패턴 실전 적용은 이번 솔루션이 처음.

## 3. 보기 구성 규칙
- **자음 분포**: 4개 보기에 각 자음이 2~3회 등장
- **A형/B형** (패턴 A): 단일 라벨 보기가 정답 라벨인 형(A) / 함정 라벨인 형(B) 약 5:5
- **가장 긴 보기 = 정답 회피**: 패턴 A의 50% 이상에서 정답과 같은 라벨 수의 오답 보기 배치
- **정답 위치**: ①②③④ 각 25% ±10%
- **함정 라벨 분포**: ㄱㄴㄷㄹ 각 25% ±10% (원예 회차는 ㄱ 0회 → 실패 사례)

### 보기 조합 예시
패턴 A (정답 ㄱㄴㄷ / 함정 ㄹ) + 긴 보기 회피:
| ① ㄱ,ㄴ | ② ㄴ,ㄷ,ㄹ (회피용 3라벨 오답) | ③ ㄱ,ㄴ,ㄷ ★ | ④ ㄷ |

패턴 B (정답 ㄱㄷ / 함정 ㄴㄹ): ① ㄱ,ㄴ ② ㄱ,ㄷ★ ③ ㄴ,ㄹ ④ ㄷ,ㄹ
패턴 C (정답 ㄴ): ① ㄱ ② ㄴ★ ③ ㄷ ④ ㄹ
패턴 D (모두 정답): ① ㄱ,ㄴ ② ㄱ,ㄷ,ㄹ ③ ㄴ,ㄷ ④ ㄱ,ㄴ,ㄷ,ㄹ★

> 구현 메모: 보기 조합은 LLM에게 맡기지 말고 **코드가 패턴·목표 정답 위치·자음 분포를 만족하는 조합을 생성**하는 편이 안정적.

## 4. 함정 설계 5유형
1. 정반대 (높다↔낮다, 줄기↔뿌리)
2. 수치 변형 (1979→1989, 0.05→0.5)
3. 주체·객체 뒤바꿈
4. 일부만 옳고 일부 거짓
5. 복합 (두 군데 모두 거짓 → 해설에 (1)(2)로 풀어씀)
- 해설에는 반드시 원문을 인용하고 "무엇을 어떻게 바꾼 함정인지" 명시

## 5. 표현 정확도 (기획안 v3.0 — v8에 약하게만 반영됨, 반드시 살릴 것)
| 유형 | 원문 | 금지 변형 |
|---|---|---|
| 의무 | 해야 한다 | 할 수 있다 / 하는 것이 좋다 |
| 금지 | 해서는 안 된다 | 하지 않는 것이 좋다 |
| 가능 | 할 수 있다 | 해야 한다 / 반드시 |
| 권고 | 권장한다 | 의무적으로 |
- 정답 진술에서 위 변형 발생 시 Validator 차단. 함정 진술에서 의도적 변형은 해설에 명시된 경우만 허용.

## 6. 난이도
- 4단계(하/중/상/최상). E-TEST 방식은 "일반 최상 + 변별 핵심".
- 최상 기준(2개 이상 충족): 여러 구절 종합 / 뒤집은 오답 판별 / 수치 비교·계산 / 개념 결합 / 단순 암기 불가
- 변별 핵심 산정: `(함정수×2) + (정반대 함정×1.5) + (진술 평균길이/30) + 패턴가중(A0 B2 C4 D1)`, 단답은 `정답 항목수×2` → 선다 상위 + 단답 상위

## 7. 기출 회피 4단계
1. 동일 문장 금지 (유사도 높음 → 차단)
2. 동일 개념 + 동일 발문 구조 금지
3. 동일 개념이라도 판단 포인트가 다르면 허용
4. 핵심 개념 반복 불가피 시 보기·함정·자료·진술순서 중 2가지 이상 변경
- 기획안 v3.0 임계값 제안: 임베딩 유사도 ≥0.82 차단, 0.70~0.81 경고 (**실측 검증 안 됨 — 튜닝 필요**)

## 8. PDF 근거 검증 4단계
- L1 핵심 개념·수치·용어 원문 일치 (필수)
- L2 직접 인용 문장 원문 동일 (필수)
- L3 OCR 오류·줄바꿈은 normalize 후 비교
- L4 자동 매칭 실패 → 수동 확인 대상 표시

## 9. 문항 품질 6항목 (LLM 판정 + 사람 확인)
발문 명확성 / 정답 유일성 / 오답 명확성 / 해설 충실성 / 사고유형 구분(변별 핵심은 비교·판단형) / 지엽 수치 암기 변별 지양

## 10. 단답형
- 정답 표기: `항목1{^}변형1, 항목2` (쉼표=항목 구분, {^}=허용 변형)
- 자동 적용: 순서 무관, 띄어쓰기 무관, 대소문자 무관
- 문항별 명시: 동의어(엄격/표준★/관대), 약어(엄격/표준★/관대), 부분점수(All-or-Nothing★/비례/최소기준)
- 선다→단답 변환: "옳은 것을 모두 골라 라벨을 쓰시오", 패턴 D는 변환 제외

## 11. 자동 중단 조건 (자동형 모드에서도 멈춤)
1. PDF 페이지 매핑 불명확
2. 기출 회피로 출제 불가 영역이 전체의 70% 이상
3. 근거 자동 매칭률 80% 미만
4. 정답 근거가 교재에서 확인되지 않는 문항 발생
